# Ready-ology prototype

A static, no-build prototype for supporting the moment when an AI and a radiologist read a breast screening case differently: helping people decide, keeping responsibility clear, and learning from the disagreement.

Live demo: https://ready-ology.vercel.app

## Run locally

It is plain HTML, CSS and JavaScript. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## What is in here

- `index.html`, `reading.html`, `library.html`, `arbitration.html`, `arbitration-case.html`: the prototype screens
- `arbitration-v2/`: a built (compiled) version of the arbitration screen
- `assets/`: fonts (with their OFL licences), logos, images

Made as part of a Royal College of Art MA project. This repository holds the prototype only; research material and interviews are not included.
